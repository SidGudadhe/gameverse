# GameVerse: Out-of-Scope & Future Phase Log
**Purpose:** Guard against feature creep and premature development.  

| Item | Proposed Feature | Target Future Phase | Reason Deferred / Out of Scope |
| :--- | :--- | :--- | :--- |
| **OOS-01** | AI Game Generation Engine | Out of Roadmap Scope | The MVP explicitly prohibits building an AI generator; creators use external engines (Godot/Unity/Phaser). |
| **OOS-02** | Real-time Authoritative Multiplayer Server | Phase 16+ / Post-MVP | HTML5/WebGL games run client-side; authoritative multi-tenant multiplayer networking adds premature GPU/server cost. |
| **OOS-03** | In-App Purchases (IAP) with WebGL bridge | Post-Launch | Requires custom engine SDK wrappers and complex payment gateways; initial launch monetizes via display & pre-roll ads. |
| **OOS-04** | Web3 / Crypto Wallet Connect | Out of Scope | Traditional, stable fiat earnings (USD/INR via Stripe/Wire) prioritize creator trust and regulatory compliance. |
| **OOS-05** | Complex Recommendation AI Machine Learning | Phase 15+ | Initial discovery is powered by curated rankings, trending algorithms, and tag filters before training deep ML models. |
